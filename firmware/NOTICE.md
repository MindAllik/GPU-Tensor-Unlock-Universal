# Firmware provenance and distribution scope

`gsp_ga10x.bin` and `gsp_tu10x.bin` are extracted byte-for-byte from the
checksummed NVIDIA 610.43.03 package in `artifacts-610.43.03.json`. The Booter
and GSP boot images are decoded unchanged from the pinned 610.43.03 source
archive. The extraction also preserves that package's complete
`usr/share/licenses/nvidia-utils/LICENSE` as `NVIDIA-LICENSE`. It is installed
with the firmware package.

The locally built firmware package includes the stock GA102, AD102, and TU102
Booter and GSP boot assets from that same source revision, plus the generated
Ampere (`v67-ga102-610.43.03.bin`), Ada (`v67-ad102-610.43.03-four-plm.bin`),
and Turing (`v67-tu102-610.43.03.bin`) payloads. Ada and Ampere use the shared
`gsp_ga10x.bin` (`.fwsignature_ad10x` / `.fwsignature_ga10x`), while Turing uses
`gsp_tu10x.bin` (`.fwsignature_tu10x`). The package build checks all payloads
and stock assets against pinned SHA-256 values before installing them.

The source archive's open-module licensing does **not** license NVIDIA firmware.
The binary package contains the NVIDIA Driver License Agreement. Its section
1.1(d) addresses distribution for open source operating-system kernels with
unchanged binary files and inclusion of the agreement. Additional limitations
apply, including NVIDIA-platform use. This source repository supplies generators
and does not distribute the NVIDIA archives or generated firmware. The generated
packages preserve the extracted agreement alongside the firmware.

The GA102 V67 constants are adapted from WildFlash1st/cmp90hx-unlock at commit
`76940ae583281daa2b883518a2e89b56c11d3a46`, patch
`driver/patches/cmp90-rejoin15/0014-6104303-cmp90hx-stockflow-rejoin14-multigpu-state.patch`,
function `_kgspCmp90FillV67Signature`. The TU102 V67 six-write payload constants
(`tu102_v67`, fill `0x000004a7`, write entry `0x10b9`, canary `0x6140`,
cleanup `0x7f27 -> 0x0ccb`, exit `0x7ea4`) are adapted from
`Zagitta/gpu-unlock` (`kernel/gpu_unlock/recipes.c`, GPL-2.0-only), building on
earlier Turing CMP research in `xrip/cmp50hx-unlock` and
`PZH1gdmu/CMP40HX-Unlock`. That license is preserved in `licenses/GPL-2.0.txt`.
The generated images are separate files; the extracted NVIDIA images are never
rewritten.

The AD102 four-PLM payload constants are adapted from
[TOTORONG's AD103_win_unlocker](https://huggingface.co/TOTORONG/AD103_win_unlocker), revision
`51df9c17ec89eb8486df52cc9079dde4bd1f9974`,
`source/firmware-tools/ad102_payload.py` (`payload()`), published at
<https://huggingface.co/TOTORONG/AD103_win_unlocker>. The source file's SPDX
identifier and repository license are GPL-2.0-only; the complete GPL version 2
text is preserved in `licenses/GPL-2.0.txt` and installed with the firmware.
Modified on 2026-10-23 to integrate only deterministic payload construction;
the upstream interpreter, disassembly and narrative documents are not copied.
The generated bytes were compared with the pinned repository's shipped
`USB/RTX4080-EXPERIMENT/ASSETS/v67-ad102-610.43.03-four-plm.bin`.
The manifest records hashes for the generator, shipped image and license.

This AD102 chain was derived from debug plaintext by that project. The
[RTX 4090 report](../docs/rtx4090-register-report.md) (from `elias-gaeros/gpu-unlock`)
separately records production execution, accepted permissions, FLR and
stock-driver persistence, and approximately doubled FP32-accumulate tensor
throughput on one card. Reproducing the payload bytes alone does not establish
those runtime properties. The upstream model demonstrates that the marker can
appear even when modeled BAR writes are ignored, so the module requires
independent permission readbacks and SEC2 HALT.

NVIDIA source files inspected during the loader audit carry their own MIT
copyright notices. The minimum helper's metadata layout and Falcon operations
follow those source contracts; `licenses/NVIDIA-MIT.txt` preserves the notice.
The inspected EFI reference's notice is in `licenses/CMP40HX-MIT.txt`.
The reference's CMP 90HX result is distinct from the measured RTX 4090
result; each project retains its own attribution and evidence.
